# CineArchivo

Proyecto Next.js para mostrar catálogo de películas y detalles.

Instrucciones rápidas:

- Instalar dependencias: `npm install`
- Ejecutar en desarrollo: `npm run dev`
- Construir: `npm run build`

Variables de entorno:

- `TMDB_API_KEY` — clave de The Movie Database (necesaria para datos reales)
- `TMDB_REGION` — región para proveedores (opcional, por defecto `MX`)

Este repositorio contiene cambios hechos para integrar `vidsrc.sbs` como
opción de reproductor y limpieza de la interfaz.
